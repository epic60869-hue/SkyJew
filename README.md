# SkyJew Mod

Fabric 26.2 companion mod for Hypixel SkyBlock.

## Current features

- Farming RNG tracker and HUD
- Storage search
- Custom item tools
- Command key system
- Notes
- Main `/sj` GUI
- Version checker

## Commands

- `/sj` — open the main SkyJew GUI
- `/sj notes` — open notes
- `/sj keys` — open command keys
- `/sj search` — search storage
- `/sj custom` — open custom item tools

## Removed

The mod no longer contains farming session recording, farming analytics/history, farming server uploading, or the Guild Collection/Leaderboard HUD.
